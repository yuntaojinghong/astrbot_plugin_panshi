七类功能，覆盖群管全场景

每个模块独立开关，按需启用，不干扰正常聊天。

01

基础管理

禁言 / 解禁 / 全体禁言 / 踢人 / 拉黑 / 撤回 / 净化 / 改名片 / 头衔 / 管理员任免 / 群名 / 群公告 / 群精华。

02

反垃圾防护

违禁词（支持正则）、刷屏检测、广告链接拦截、复读打断。命中自动撤回 + 禁言 + 记警告。

03

入群欢迎（增强）

多模板随机、变量替换 {at}{昵称}{群名}{人数}{时间}、支持图片与延时发送。

04

算术验证

新人答对算数题才通过，超时自动拒绝。有效拦截广告机器人批量进群。

05

进群审核

白词自动批准、黑词自动拒绝、未命中策略可选、黑名单管理、退群通知与拉黑。

06

三级警告

违规累计自动升级：达阈值自动禁言 → 再达阈值自动踢出。支持撤销与历史查询。

07

群活跃

每日签到、积分系统、积分榜与发言榜。零数据库依赖，JSON 文件持久化。

08

自动化

宵禁时段自动全体禁言，定时公告发布。到点自动执行，无需值守。

核心：混合模式的智能识别

指令秒回不耗 token，模糊表述交给 AI —— 既快又聪明。

张三又在群里发广告，处理一下
⚠️ 检测到广告链接，已撤回并禁言 10分钟（累计警告 1 次）
把刚才那个刷屏的也禁言半小时
✅ 已禁言 李四 30分钟
@王五 再发链接就把你踢了
⚠️ 即将执行高风险操作：踢出 王五，原因：发链接
请在 60 秒内回复「确认」执行，或「取消」放弃。
确认
✅ 已将 王五 踢出（原因：发链接）
消息进来
├─ 是 /指令  → 直接执行（零 token，毫秒级）
└─ 像在指挥机器人 → 交给 LLM 解析意图
    ├─ 收集上下文（引用 / 最近发言 / @对象 / 群成员）
    ├─ 输出结构化 JSON
    ├─ 目标解析（名字模糊匹配 / 刷屏者推断）
    ├─ 权限校验
    └─ 高风险操作 → 确认后执行

四路目标定位

引用消息 > @某人 > QQ号 > 名字模糊匹配，自动选择最准确的一种。

上下文推断

结合最近发言记录，理解「刚才刷屏的」「发广告的那个」到底指谁。

高危确认

踢人、拉黑等不可逆操作先复述再执行，杜绝 AI 误判造成损失。

相对传统群管插件的改进

站在成熟方案的肩膀上，重新设计交互体验。

维度传统做法磐石

交互方式 只认固定指令 自然语言，听得懂人话
违规处理 直接禁言 三级警告，累计自动升级

三步装好

需要 AstrBot 4.5+ 与 NapCat（OneBot v11）协议端。

1

拉取插件

进入 AstrBot 的插件目录，克隆本仓库。

cd AstrBot/data/plugins
git clone https://github.com/yuntaojinghong/astrbot_plugin_panshi.git
2

重启并配置

重启 AstrBot，在 WebUI 插件页找到「磐石 · 智能群管」，按分组调整配置：基础设置、反垃圾防护、入群欢迎、警告系统、智能识别、群活跃、自动化。

3

开始使用

发送 /群管帮助 查看完整指令，或直接对机器人说人话。

/禁言 @某人 10m    禁言十分钟
/踢 @某人 发广告    踢出并注明原因
/警告 @某人 刷屏    记一次违规
/净化 30             批量撤回最近30条
/签到                 每日签到得积分
