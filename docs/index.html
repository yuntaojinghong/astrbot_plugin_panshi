// FEATURES

七类功能，覆盖群管全场景

每个模块独立开关，按需启用，不干扰正常聊天。

01

基础管理

禁言 / 解禁 / 全体禁言 / 踢人 / 拉黑 / 撤回 / 净化 / 改名片 / 头衔 / 管理员任免 / 群名 / 群公告 / 群精华。

  • 时长支持人性化单位：30s 10m 2h 1d，不用再心算秒数
  • 目标定位四选一：引用消息 > @某人 > QQ号 > 名字模糊匹配
  • /禁言 /解禁 /全体禁言 /踢 /拉黑 /撤回 /净化 等 13 个指令全覆盖
  • /踢 /拉黑 等高危操作支持附带原因，机器人复述后执行并留痕
详细说明▼
02

反垃圾防护

违禁词（支持正则）、刷屏检测、广告链接拦截、复读打断。命中自动撤回 + 禁言 + 记警告。

  • 违禁词支持普通关键词与正则表达式，命中即 撤回 + 禁言 + 记警告，三个动作均可单独开关
  • 刷屏检测：时间窗 + 条数双参数可调（默认 10 秒 8 条），可触发打断与自动处罚
  • 广告链接识别常见推广域名与邀请码模式，白名单域名放行
  • 复读打断：识别恶意复读接龙，及时掐断刷屏氛围
详细说明▼
03

入群欢迎（增强）

多模板随机、变量替换 {at}{昵称}{群名}{人数}{时间}、支持图片与延时发送。

  • 多模板随机轮播，每天进群看到不一样的欢迎语
  • 变量替换：{at} {昵称} {群名} {人数} {时间} 自由组合
  • 支持图片 URL 图文混排，欢迎语更有温度
  • 可设置延时发送（如进群 3 秒后），每个群可用独立模板
详细说明▼
04

算术验证

新人答对算数题才通过，超时自动拒绝。有效拦截广告机器人批量进群。

  • 新人进群自动出题，限时作答：答对放行，超时或答错自动移出
  • 题目难度（位数范围）与超时时长均可配置
  • 可选验证失败后自动拉黑，拦截批量注册的小号
  • 对广告机器人批量进群几乎是零误放的拦截方案

05

进群审核

白词自动批准、黑词自动拒绝、未命中策略可选、黑名单管理、退群通知与拉黑。

  • 白词命中自动批准，黑词命中自动拒绝并通知管理员
  • 未命中任何词时可选择策略：人工审核 / 自动批准 / 自动拒绝
  • 黑名单 QQ 永久拒绝入群申请
  • 成员退群可发通知提醒，并可选自动拉黑防止反复进群

06

三级警告

违规累计自动升级：达阈值自动禁言 → 再达阈值自动踢出。支持撤销与历史查询。

  • 每次违规记一条警告，附带原因与操作人，有据可查
  • 达到第一阈值自动禁言（时长可配），达到第二阈值自动踢出，逐级升级
  • /警告记录 @某人 随时查询历史，/撤销警告 可回退误判
  • 警告数据按群独立存储，互不干扰

07

群活跃

每日签到、积分系统、积分榜与发言榜。零数据库依赖，JSON 文件持久化。

  • /签到 每日一次得积分，连续签到有递增加成
  • 积分榜、发言榜一键查看，活跃度一目了然
  • 纯 JSON 文件持久化，零数据库依赖，备份就是拷文件
  • 签到分、加成上限等数值均可在面板调整

08

自动化

宵禁时段自动全体禁言，定时公告发布。到点自动执行，无需值守。

  • 宵禁：按时段自动全体禁言、出段自动解除，支持跨零点（如 23:30-07:00）
  • 定时公告：按设定间隔自动向所有纳管群推送公告内容
  • 群列表动态刷新，新进群即刻纳管，退群自动移除
  • 面板改配置即时生效，无需重启 AstrBot

// NATURAL LANGUAGE

核心：混合模式的智能识别

指令秒回不耗 token，模糊表述交给 AI —— 既快又聪明。

张三又在群里发广告，处理一下
⚠️ 检测到广告链接，已撤回并禁言 10分钟（累计警告 1 次）
把刚才那个刷屏的也禁言半小时
✅ 已禁言 李四 30分钟
宵禁改到23点半到7点
🌙 宵禁已开启 · 时段 23:30 ~ 07:00
🟢 已开启，到点会自动全体禁言。
@王五 再发链接就把你踢了
⚠️ 即将执行高风险操作：踢出 王五，原因：发链接
请在 60 秒内回复「确认」执行，或「取消」放弃。
确认
✅ 已将 王五 踢出（原因：发链接）
intent-pipeline
消息进来
├─ 是 /指令  → 直接执行（零 token，毫秒级）
└─ 像在指挥机器人 → 交给 LLM 解析意图
    ├─ 收集上下文（引用 / 最近发言 / @对象 / 群成员）
    ├─ 输出结构化 JSON
    ├─ 目标解析（名字模糊匹配 / 刷屏者推断）
    ├─ 权限校验
    └─ 高风险操作 → 确认后执行

四路目标定位

引用消息 > @某人 > QQ号 > 名字模糊匹配，自动选择最准确的一种。

  • 解析优先级：引用消息 > @某人 > 消息中的 QQ 号 > 名字模糊匹配
  • 遇到重名时结合最近发言与活跃度消歧
  • 目标不存在或权限不足时明确提示原因，不静默失败
详细说明▼

上下文推断

结合最近发言记录，理解「刚才刷屏的」「发广告的那个」到底指谁。

  • 「刚才刷屏的」「发广告的那个」结合最近消息缓存直接定位到人
  • 谁触发过刷屏检测、谁的消息被撤回过，都记录在案可推断
  • 缓存定期自动清理，长期运行不膨胀
详细说明▼

高危确认

踢人、拉黑等不可逆操作先复述再执行，杜绝 AI 误判造成损失。

  • 踢人、拉黑等不可逆操作先复述「做什么 + 为什么」
  • 60 秒内回复「确认」才执行，「取消」或超时自动放弃
  • 杜绝 AI 误判误伤正常群友

// GET STARTED

三步装好

需要 AstrBot 4.24.2+ 与 NapCat（OneBot v11）协议端。4.24.2 以上才支持配置面板。

ZIP 下载压缩包最新版 · 直达 Release 页 TGZ 下载 tar.gz最新版 · 直达 Release 页 GIT 克隆仓库main 分支
1

获取插件

打开 Release 页下载压缩包，解压到 AstrBot 的插件目录；或直接克隆仓库。

cd AstrBot/data/plugins
git clone https://github.com/yuntaojinghong/astrbot_plugin_panshi.git
2

重启并在面板里配置

重启 AstrBot，进入插件详情页 → Pages → settings，打开图形配置面板。 面板会自动识别机器人所在的所有群，可按群独立设置规则；也可以直接在插件配置页调整七组配置项。

3

开始使用

发送 /群管帮助 查看完整指令，或直接对机器人说人话。

/禁言 @某人 10m    禁言十分钟
/踢 @某人 发广告    踢出并注明原因
/警告 @某人 刷屏    记一次违规
/净化 30             批量撤回最近30条
/签到                 每日签到得积分
